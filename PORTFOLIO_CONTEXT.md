# Portfolio context

This is a sanitized, local-first portfolio implementation of a generic invoice process dashboard.

## What it demonstrates

- Invoice input contracts, ETL and SQLite handoffs.
- Calendar, override, SLA and export workflows.
- Static browser dashboard, generated assets and operator automation.
- Synthetic end-to-end, safety, transaction and browser validation.

## My contribution

I led the implementation and technical review across the invoice ETL, SQL and database contracts, dashboard flows, operator automation, safety gates, tests and documentation. This shows end-to-end application delivery beyond my official Data Analyst title.

## AI-assisted engineering

AI tools were used daily as an engineering accelerator for implementation, refactoring, documentation, test design, code review and repeatable QA. The resulting code and synthetic contracts were reviewed and validated locally.

The wider engineering workflow also uses an LLM harness, MCP integrations and retrieval-oriented context workflows where useful; these tools are not required to run this local demo.

## Data boundary

All invoice rows, identities, source-system codes and configuration values are synthetic or generic placeholders. No production data, credentials or tenant configuration is included.
